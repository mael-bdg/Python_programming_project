# Interactive Movie Recommendation System 

## Description

The Interactive Movie Recommendation System requires students to develop a Python-based
application that recommends movies based on user preferences.
The system must incorporate a database component to ensure structured and persistent
storage of movie data.

## 📅 Submission Details
Course: Python Programming 
Deadline: 5 June 2026 

## Features

### Main Features
- Interactive graphical user interface using Tkinter
- Movie recommendation based on selected genre
- SQLite database integration
- Display of movie titles and synopsis
- Genre selection using a dropdown menu
- CRUD database operations:
  - Create
  - Insert
  - Retrieve
  - Update
  - Delete

## Launch

How to launch our Project : 

Run the following command in the terminal:
```bash
python main.py
```

When the application is launched for the first time:

- the SQLite database is automatically created
- movie data is loaded from `brouillon.sql`
- the graphical interface opens automatically

### Example

1. Select a movie genre from the dropdown menu.

Example:

```text
Sci-Fi
```

2. Click the **"Recommend Movies"** button.

3. The application displays movie recommendations matching the selected genre.

Expected output example:

```text
Movies for Sci-Fi:

🎬 Matrix
A hacker discovers that his reality is only a computer simulation.

🎬 Arrival
A linguist attempts to communicate with aliens.
```

Users can select different genres to receive other movie recommendations.
